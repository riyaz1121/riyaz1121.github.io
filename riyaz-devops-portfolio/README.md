# Shaik Riyaz Basha — DevOps Portfolio

A responsive, single-page personal portfolio for AWS DevOps, Kubernetes, Terraform, CI/CD, and SRE work. Built with plain HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a GitHub repository named **`riyaz1121.github.io`**.
2. Upload all files and folders from this project to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. After deployment, visit `https://riyaz1121.github.io`.
